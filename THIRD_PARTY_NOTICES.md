# Assets et composants tiers

Les logos Claude, OpenAI/Codex et OpenCode proviennent de [The SVG](https://github.com/GLINCKER/thesvg/tree/main/public/icons). La licence MIT du dépôt source est reproduite dans `docs/thesvg-LICENSE.txt`. Les marques restent la propriété de leurs titulaires ; TokenDock n’est pas affilié à ces entreprises.

Le chat, les icônes Musique/Copies et l’icône de l’application ont été générés avec imagegen. Les géométries caméra et commandes de lecture sont dessinées par le code. Les pochettes et photos des utilisateurs ne sont pas distribuées.

Le concept d’encoche est inspiré de [boring.notch](https://github.com/TheBoredTeam/boring.notch). Aucun code Swift de ce projet n’est inclus. TokenDock est une implémentation Windows WPF.

L’archive autonome inclut le runtime Microsoft .NET et ses notices de licence. Les API Windows de caméra, média et presse-papiers restent des composants système.
